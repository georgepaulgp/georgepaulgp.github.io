Bayesian Nonparametric Quantile Function Modelling for Tail Risk

Research proposal – functional Gaussian process quantile regression

This research proposal develops a Bayesian nonparametric model for the entire conditional quantile function of returns, treated as a smooth surface q(α, x) over quantile level α and predictors x. Rather than fitting separate quantile models independently, the idea is to model the full quantile surface jointly so that tail-risk forecasts remain coherent across multiple confidence levels.

The core object is the conditional quantile function q(α, x), where α lies between 0 and 1 and x contains lagged returns and volatility-related predictors. The proposal places a functional Gaussian process prior over this surface:

q(α, x) ~ GP(m0(α, x), K((α, x), (α′, x′)))

where m0(α, x) is the prior mean function and K is a covariance kernel. A separable kernel is used so that dependence across quantile levels and dependence across predictors can be controlled separately:

K((α, x), (α′, x′)) = Kα(α, α′) Kx(x, x′)

A key modelling requirement is monotonicity: if α1 < α2, then q(α1, x) ≤ q(α2, x). To enforce this, the proposal introduces a non-negative latent function f(α, x) and defines the quantile function as an integral:

q(α, x) = ∫0α f(u, x) du

with f(α, x) ≥ 0. On a discrete grid of quantile levels, this becomes:

qk(x) = ∑j=1k fj(x)Δα

which guarantees ordered quantiles by construction.

The latent function is built from an unconstrained Gaussian process g(α, x), transformed using a smooth positive mapping:

g(α, x) ~ GP(0, K)
f(α, x) = log(1 + exp(g(α, x)))

This softplus transformation ensures positivity while remaining differentiable, which is helpful for efficient optimisation and variational inference.

For inference, returns rt+1 are linked to the quantile surface using the asymmetric Laplace likelihood for each quantile level αk. In compact form:

p(rt+1 | qk(xt), αk) ∝ exp(-ραk(rt+1 - qk(xt)))

where the quantile loss function is

ρα(u) = u(α - 1(u < 0)).

Because the posterior is analytically intractable, the proposal uses constrained variational inference with sparse Gaussian process approximations. The variational objective is the evidence lower bound:

L = Eq[log p(r | g)] - KL(q(g) || p(g))

where the first term encourages fit to the observed return data and the second penalises deviation from the prior. Sparse inducing-point approximations are used to make estimation feasible on long financial time series.

Empirically, the project focuses on S&P 500 daily returns from 1990 to 2025, using predictors such as lagged returns, realised-volatility proxies, rolling volatility estimates and market indicators. The model will be assessed against GARCH, Bayesian parametric quantile regression and machine-learning quantile benchmarks using quantile loss, CRPS, VaR/ES backtests and the economic performance of volatility-timing strategies under transaction costs.

Advancing Hierarchical Bayesian Neural Networks for Building Energy Use

MSc research project · Distinction (81%)

For my MSc dissertation, I developed hierarchical Bayesian neural network models for predicting Energy‑Use Intensity (EUI) in office buildings. The goal was to move beyond single point forecasts and produce uncertainty‑aware predictions that remain interpretable for carbon and energy‑performance assessment. The models combined building‑level covariates (e.g. floor area, age, location and usage type) with a hierarchical structure that captures group‑level effects and heterogeneity across building segments.

Technically, I used Bayesian neural networks with group‑specific parameters and hyperpriors that pool information across buildings while allowing segment‑level deviations. Priors were chosen to favour parsimonious structures but still permit non‑linear responses in key drivers of energy use. Posterior inference was implemented using Hamiltonian Monte Carlo and variational techniques; posterior predictive checks, prior‑sensitivity analysis and out‑of‑sample calibration diagnostics were used to stress‑test model assumptions. The result was a set of EUI forecasts with credible intervals that support transparent, audit‑aligned building benchmarking rather than opaque black‑box predictions.

This work directly informed later projects on emissions traceability and carbon‑risk modelling, and gave me hands‑on experience balancing model flexibility, interpretability and computational cost in real sustainability datasets.
